📚 Orientações Técnicas

Utilize as orientações abaixo durante a análise do problema e registre os procedimentos realizados no formulário de atendimento.
1. Confirmar os dados cadastrais do cliente.
2. Confirmar o telefone registrado.
3. Verificar se os números estão divergentes.
4. Realizar troca das senhas do usuário de voz quando necessário.
5. Verificar privacidade do número.
6. Verificar recebimento de chamadas a cobrar.
7. Realizar o desprovisionamento quando aplicável.
8. Realizar teste audível.

Em caso de telefone inoperante, verificar:

  • Para onde o cliente está ligando.
  • Número chamado.
  • Operadora.
  • Modelo do aparelho telefônico.
  • Possíveis travas no aparelho.
  • Se o aparelho é Plug and Play ou ramal.
⚠️ Caso seja ramal, o telefone não funcionará conforme o procedimento descrito no material.
